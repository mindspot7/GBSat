# Layout check on handheld screens

Rendered from the app's UI code by `DeviceScreens` (workflow "README screenshots") to check the layout on the
screens of the most common handhelds: 640x480 (Rockchip RK3566 devices, at mdpi and hdpi), 720x960 portrait,
1240x1080 and 1920x1080. Not used in the README.
