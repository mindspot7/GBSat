# Layout check on handheld screens

Rendered from the app's UI code by `DeviceScreens` (workflow "README screenshots") to check the layout on the
screens of the most common handhelds: 640x480 (RG DS; at mdpi it also matches 1280x960 4:3 screens), 720x720 square
(RG Rotate, RG Cube), 720x960 portrait, 1240x1080 (Retroid Pocket Classic) and 1920x1080 (Mangmi Air X). Not used in the README.
